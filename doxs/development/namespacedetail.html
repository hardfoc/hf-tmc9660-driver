Detailed Description

Write a global parameter value using TMCL SGP command.

Sends a Set Global Parameter (SGP) command to configure module-wide settings such as communication parameters, GPIO configuration, and system settings. Global parameters affect the entire TMC9660 module, not just motor control.

Parameters
idGlobal parameter identifier (supports multiple parameter types)
bankParameter bank (0=module, 2=user, 3=system)
valueParameter value to write
Returns
true if parameter was written successfully
