Detailed Description

template<typename CommType>
struct tmc9660::TMC9660< CommType >::RamDebug::Channel

One capture or trigger source.

Encoded as the VALUE of types 4/5: motor_or_bank << 24 | (number & 0xFFF) with the channel type in MOTOR/BANK (reference manual Table 16 and "Set Up the Channels").
