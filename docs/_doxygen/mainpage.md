# TMC9660 Driver API reference {#mainpage}

The classes, members and parameters of the HardFOC TMC9660 driver, generated from the headers.

Start with tmc9660::TMC9660, the driver and its subsystems, and tmc9660::SpiCommInterface or
tmc9660::UartCommInterface, the interface your platform port implements. TMCL parameters and enums are in the
tmc9660::tmcl namespace; the bootloader configuration is tmc9660::BootloaderConfig.

The guides, with examples that compile, are on the documentation site: <a href="../">TMC9660 Driver
documentation</a>.
