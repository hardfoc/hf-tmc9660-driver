Detailed Description

Full read-only state dump from the chip.

Velocity / position fields carry both the raw int (*_internal / *_counts / *_phi_e) and the engineering-unit form. The unit-form fields are populated using the MotorContext passed to the populating call, so they are only meaningful when context.valid().
