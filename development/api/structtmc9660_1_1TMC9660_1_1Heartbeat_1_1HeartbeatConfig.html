Enable heartbeat monitoring (optional, default: false).

When enabled, the TMC9660 monitors communication timeout and faults if no commands are received within the timeout period. Enable heartbeat monitoring (optional, default: false)

template<typename CommType >
std::optional<tmc9660::tmcl::HeartbeatMonitoringConfig> tmc9660::TMC9660< CommType >::Heartbeat::HeartbeatConfig::interface

Interface the watchdog monitors when enabled (optional).

Default: the transport this driver instance talks over (transportInterface()), i.e. SPI_INTERFACE on SPI boards. Releases up to 1.0.0 always armed TMCL_UART_INTERFACE, which on an SPI board never sees traffic. Set TMCL_UART_AND_SPI_INTERFACE to watch both. Ignored when enable is false.
