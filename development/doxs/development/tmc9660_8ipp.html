float calculateBootstrapCurrent_mA ( float gateCharge_nC,
float pwmFreq_Hz )
inlinenoexcept

Estimate the bootstrap supply current a three-phase power stage needs.

Each high-side turn-on transfers the FET gate charge gateCharge_nC out of the bootstrap capacitor, so the average current scales with switching rate: I = (Qg × N_phases × f_PWM) / duty × margin. The result is used to pick the smallest tmc9660::tmcl::BootstrapCurrentLimit setting that still covers the stage.

Parameters
gateCharge_nCTotal gate charge of one high-side FET, in nanocoulombs.
pwmFreq_HzPWM switching frequency, in hertz.
Returns
Required bootstrap current in milliamps, including safety margin.
Note
Assumes three high-side FETs and 50% average duty, then applies a 2.5x margin to cover duty peaks and gate-loop losses. Marked inline rather than static because it is defined in a header and only referenced from templates, which would otherwise warn as unused in translation units that never instantiate them.
