Detailed Description

template<typename CommType>
struct tmc9660::TMC9660< CommType >::Heartbeat

Subsystem for configuring the communication watchdog (heartbeat).

If enabled, the TMC9660 monitors the time since the last command. If no communication occurs before timeout expires, the chip faults or disables motor outputs.

Global bank 0 parameters 3 (HEARTBEAT_MONITORING_CONFIG) and 4 (HEARTBEAT_MONITORING_TIMEOUT), written with SGP — never with SAP, where ids 3/4 are MOTOR_PWM_FREQUENCY / COMMUTATION_MODE (Parameter Mode Reference Manual, global parameters bank 0). The watchdog only sees datagrams on the interface(s) it monitors, so it must be armed for the interface the host actually uses: SPI on SPI-connected boards such as Vortex V1.
