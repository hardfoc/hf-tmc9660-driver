Detailed Description

ADC Status Flags Register for monitoring ADC health and readiness.

Provides real-time status information about each ADC channel including readiness flags, watchdog failures, and sequence configuration errors. These flags are essential for monitoring ADC calibration status and detecting measurement failures that could affect motor control accuracy.

Watchdog failures indicate ADC measurement timeouts, while sequence configuration errors suggest improper multiplexer setup that could lead to incorrect measurements or system instability.

Status flags for the ADC block.
