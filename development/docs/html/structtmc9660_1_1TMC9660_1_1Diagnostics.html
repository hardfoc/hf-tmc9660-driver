Detailed Description

template<typename CommType>
struct tmc9660::TMC9660< CommType >::Diagnostics

One-shot diagnostic snapshots for upstream health reporting.

Two flavours:

  • summary(MotorSummary&) — small, single-screen health (vbus, temp, mode, target/actual RPM, regulating flag, fault summary). Cheap.
  • snapshot(MotorSnapshot&, MotorContext const&) — full chip state in both raw and engineering-unit form. Use for logging, bench expectation-checking, or upstream telemetry packets.

Both methods are best-effort: a failed individual SAP leaves the corresponding field at its struct default. The methods themselves always succeed (return value is reserved for future use).
