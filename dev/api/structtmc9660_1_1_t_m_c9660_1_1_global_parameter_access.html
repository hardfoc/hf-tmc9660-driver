Detailed Description

template<typename CommType>
struct tmc9660::TMC9660< CommType >::GlobalParameterAccess

One element of a batched global-parameter access (SGP/GGP).

Constructed only from a GlobalParamBank0/2/3 id, so the bank always matches the id. An axis tmcl::Parameters id does not convert (compile error), which keeps axis and global ids on their own banks.
