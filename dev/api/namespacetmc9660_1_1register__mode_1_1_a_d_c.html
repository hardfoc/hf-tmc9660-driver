Detailed Description

ADC and analog measurement namespace for TMC9660.

This namespace contains all ADC-related register definitions, configuration structures, and measurement capabilities for the TMC9660 motor driver. It provides comprehensive analog measurement support for motor control feedback and system monitoring.
